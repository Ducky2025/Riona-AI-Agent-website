## 🔧 **TROUBLESHOOTING**

### **Common Issues & Solutions:**

| Issue | Cause | Solution |
|-------|-------|----------|
| **"Backend not available"** | Local server not running | Start: `npm start` in production directory |
| **"Instagram login failed"** | Wrong credentials or 2FA | Check username/password, disable 2FA |
| **"Automation not starting"** | Browser/Puppeteer issue | Install Chrome dependencies |
| **"API errors"** | Missing dependencies | Run: `npm install` |
| **"No statistics showing"** | Client not initialized | Restart automation |
